THOCK — install

1. Drag Thock.app onto the Applications folder.
2. Because this build is signed ad-hoc (not notarized), the first launch must be done like this:
   right-click Thock in Applications → Open → Open.
   (If macOS still refuses: System Settings → Privacy & Security → "Open Anyway", or run
    xattr -dr com.apple.quarantine /Applications/Thock.app )
3. Thock lives in the menu bar (keyboard icon). When asked, grant Input Monitoring:
   System Settings → Privacy & Security → Input Monitoring → switch Thock on.
4. Type. Choose a switch sound from the menu bar or Settings.
